# 🧮 Calculadora React de IMC
 
Projeto desenvolvido como exercício prático do Módulo 28, para praticar conceitos de React (componentização, estados e eventos) na construção de uma calculadora de IMC.
 
## ✨ Funcionalidades
 
- Operações matemáticas básicas (soma, subtração, multiplicação e divisão)
- Interface simples e responsiva
- Gerenciamento de estado com React Hooks
  
## 🚀 Tecnologias utilizadas
 
- React
- Vite
- JavaScript
- CSS
- HTML
  
## 📦 Como rodar o projeto
 
```bash
# Clone o repositório
git clone https://github.com/aarielmartins/MOD_28_Calculadora_React.git
 
# Acesse a pasta
cd MOD_28_Calculadora_React
 
# Instale as dependências
npm install
 
# Rode o projeto
npm run dev
```
